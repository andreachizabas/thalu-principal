# Frontend ThaLu

Aplicacion web de ThaLu By Andrea Chizabas con Next.js, React, TypeScript,
Tailwind CSS, Motion y estado local para la primera experiencia de carrito.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Variables

- `NEXT_PUBLIC_API_URL`: URL del backend Go. Valor local: `http://localhost:8080`.
- `NEXT_PUBLIC_SITE_URL`: URL publica del sitio cuando exista despliegue.

## Scripts

- `npm run dev`: desarrollo.
- `npm run lint`: validacion ESLint.
- `npm run build`: compilacion de produccion.
